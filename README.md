# Competitive Coding

A structured collection of algorithm and data-structure solutions, organized by problem number and title. Each problem is kept in its own directory so the solution, explanation, and tests can evolve independently.

## What is included

- Array, string, linked-list, tree, graph, and dynamic-programming problems
- One directory per problem, using a stable numeric prefix
- Problem-specific README files with the prompt and approach
- Solutions intended for practice, review, and interview preparation

## Repository layout

```text
0002-add-two-numbers/
  README.md
  ...
0003-longest-substring-without-repeating-characters/
  README.md
  ...
```

## How to use

1. Pick a problem directory.
2. Read its README without looking at the implementation.
3. Implement or explain the approach yourself.
4. Compare with the solution and note the time and space complexity.

The repository is language-agnostic at the collection level; use the language and execution instructions documented inside each problem directory.

## Adding a problem

Create a directory named `<problem-number>-<short-title>`, add the problem README, solution, complexity analysis, and focused tests where appropriate. Keep names lowercase and preserve the numeric ordering.
